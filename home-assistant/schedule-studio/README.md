# Schedule Studio

Schedule Studio is a local-first weekly planning app for seeing where time actually goes. It stores schedule data in SQLite inside the add-on's persistent `/data` directory and opens through Home Assistant Ingress.

## About

- Weekly schedule templates with saved versions
- Drag-and-resize time blocks and pins
- Category budgets and daily/weekly totals
- Local SQLite persistence included in Home Assistant add-on backups

## Open Web UI

Install the add-on, start it, then select **Open Web UI** from the add-on page.
