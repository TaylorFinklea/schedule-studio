# Changelog

## 0.1.6

Changes since the June 0.1.5 add-on release:

- Add per-day scheduled-time summaries with parent-category rollups; new subcategories inherit their parent's color.
- Add the Schedule Studio logo and favicon.
- On phone-width screens the to-do sidebar starts collapsed (until you expand it) so the timeline has room and its blocks can be tapped.

## 0.1.5

- Add schedule week anchoring, date-less weekday labels, all-day visible bounds controls, and pinned day labels in rows view.

## 0.1.1

- Fix SQLite startup on Home Assistant by allowing the app to write the add-on `/data` mount.

## 0.1.0

- Initial Home Assistant add-on packaging.
- Runs Schedule Studio through Home Assistant Ingress.
- Stores SQLite data in persistent add-on `/data` storage.
